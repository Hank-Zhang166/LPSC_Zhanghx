# 构型概率排序演示

示例以随机选择一个结构族的相对晶内输运 $S_x=\log(\sigma_{\mathrm{grain},x}/\sigma_\mathrm{ref})$ 为决策变量，同时传播该族潜在输运量的不确定性。$\sigma_\mathrm{ref}$ 是演示模型的任意标度。构型族是合成假说，权重表达给定热历史和结构观测条件下的假说概率。要把概率解释为样品域的体积分数，还需建立和验证空间混合、连通性及观测模型。

## 运行和复核

在项目根目录执行。运行环境需要 Python 3.10 及以上和 NumPy，实际版本记入 `outputs/metadata.json`。

```powershell
python p9/ranking/run_demo.py
python -m unittest discover -s p9/ranking -p "test_*.py" -v
```

默认种子 20261124，运行 128 个共享参数情景，每个情景作 256 次七配方联合抽样。可用 `--seed`、`--worlds`、`--repetitions` 与 `--output` 重跑和检查 Monte Carlo 精度。Mo 等 Table S1 使用 `p9/evidence/mo_s1.csv`，其 SHA-256 见 `metadata.json`。该表只在模拟结束后进入历史点方向比较。

## 占位约束与结构族支持集

设 $k=10x$ 为 0–6 的整数，每胞取 20 个 P。计数严格为 $\mathrm{Li}_{120-2k}\mathrm{P}_{20}\mathrm{S}_{100-2k}\mathrm{Cl}_{20+2k}$，总原子数 $260-2k$。用固定的 80 个 P 周边框架 S 和各有 20 位的两个自由阴离子子晶格 A、B 作理想化计数。每个自由阴离子位被 S 或 Cl 单占，$n_\mathrm{Cl,A}+n_\mathrm{Cl,B}=20+2k$，二者均在 0–20。Li 以总数及相对 $x=0$ 减少的 $2k$ 作约束。实际 Li 部分占位与排斥拓扑需在晶胞和坐标确定后建模。

`integer_cell_options.csv` 提供 6 个基于理想 fcc 原胞、行基变换行列式为 20 的整数超胞候选，原胞假设为每胞 1 个 P。列 `basis_condition_ratio` 是相对于理想基底的原始非规约基矩阵奇异值之比，供初筛。真实候选还要做格基规约、最短周期距离、迁移网络和尺寸敏感性检查。

`occupancy_profiles.csv` 枚举 105 个子晶格计数档。组合数 $\binom{20}{n_\mathrm{Cl,A}}\binom{20}{n_\mathrm{Cl,B}}$ 只计自由阴离子标号布置，不含局域几何、Li 排斥或真实群简并。示例按每个 $x$ 的 $n_\mathrm{Cl,A}$ 把可行区间分为低、中、高三层，从每层左、中、右取 3 个确定性档，共 63 个离散合成支持点。族内局域代理量、代表能量与简并值为示范输入。三个层标签表示 Cl 从一个子晶格向另一个子晶格的合成分配档，跨组成的数字边界随可行区间变化。

真实计算起点可以是具备来源、占位和许可记录的母体结构。母体外部条件先验和晶位约定见 [公开证据登记](../evidence/STRUCTURE_LITERATURE.md)。在真实母体上生成并松弛候选后，需核对价态计数、Li 位互斥、最小原子间距、周期连通性，再按晶体对称性、局域环境和结构族去重。可按子晶格置换分数、近邻短程秩序及 Li 局域环境分层，保留跨层的稀有但决策敏感构型。几何支持集确认前，本演示只输出整数矩阵、计数和合成输入，不构造 CIF。

## 热力学先验和 BME

对同组成、同能量口径的有效结构族，采用 $\log w_i^0=\log g_i-[F_i(T_f)-F_{\min}(T_f)]/(k_BT_f)-\log\mathcal Z$。模型用整胞 eV 及 log-sum-exp，$T_f$ 为结构冻结的情景温度。演示中央结构诊断用 675 K，传播范围 525–825 K，数值无需解释为炉温或实测冻结温度。尽管物理运行可用独立 DFT 校验 DPA4 相对能，当前 `cell_relative_eV_synthetic` 来自生成式假设。

如果 $F_i$ 已含族内熵，省略 $g_i$。非均匀 IID 提议采样时对每次抽样修正 $-\log q_i$，合并重复族之前应保留抽样重复次数，并检查 $q_i$ 对目标支持的覆盖。独立生成计数档按所列支持排序时无 $q_i$ 修正。直接从目标平衡分布获得的去相关 MCMC 样本用留存族频率估计；链方法还需核对独立链、混合和自相关有效样本量。

演示的两项训练观测是子晶格 Cl 分数代理和局域对关联代理，第三项合成代理只用于结构留出诊断。它们是可线性加权的示范观测。$\hat z=w^TF$，误差尺度 $\Sigma=\Sigma_\mathrm{exp}+\Sigma_\mathrm{forward}+\Sigma_\mathrm{shared}$，三项均为声明的假设协方差，含相应非对角项。真实衍射、相混、归一化或谱线应从物理前向模型检查可加性。用常规 XRD 优先限定位相、晶格和残相，由成分测量、占位精修或局域表征提供另行验证的约束。

求解的目标是 $\tfrac12\|L^{-1}(\hat z-z)\|^2+\lambda\sum_i w_i\log(w_i/w_i^0)$，$LL^T=\Sigma$。置 $d_i=L^{-1}[f(C_i)-z]$，用阻尼 Newton 解对偶 $\log\sum_i w_i^0 e^{-d_i^T\eta}+\lambda\|\eta\|^2/2$，得 $w_i\propto w_i^0e^{-d_i^T\eta}$。演示预先固定 $\lambda=1$，并公开 0.25、1、4 的残差、留出预测及权重集中度。实际应冻结独立结构留出或基于合理先验作敏感性判断，EIS 比较只在模型之外使用。

诊断报告 $1/\sum_i w_i^2$、最大权重、KL、训练标准化残差及到支持凸包的最小 Mahalanobis 距离。线性训练观测只有两个维度，候选族多于可识别方向。即使观测落在凸包内，也只能找到若干相容结构权重；BME 为与先验正则化相容的一点。偏移观测的压力测试演示怎样发现支持缺口。观测明显在支持之外时，应复核前向模型和误差，再补充支持或发起诊断。

| 方法 | 适用证据和投入 |
| --- | --- |
| 占位精修 | 有足够衍射/总散射信号与可靠多相/占位约束时给直接的平均结构限制 |
| MC / cluster expansion | 有可迁移配置能模型和可检验热历史时生成更丰富的构型与短程有序；训练和链收敛需要资源 |
| 重要性采样 | 已知提议密度且目标支持被覆盖时，可复用候选；极端权重需要改善提议或分层 |
| BME | 支持集及低维观测算子可构造时，先给透明的点更新、诊断和敏感性；本演示采用 |
| 贝叶斯反演 | 能明确参数先验、独立验证似然和结构不可辨识性时，可给完整后验或部分识别区间 |
| RMC / HRMC | 有高质量散射数据以及可用原子势和长程/局部约束时，适合更深的逆向结构重建 |

方法参照 Bottaro 等 [BME 方法及代码](https://github.com/KULL-Centre/BME) 和 Cuillier 等 [RMCProfile–LAMMPS 联用](https://doi.org/10.1107/S1600576724009282)。适用体系、可核实内容与迁移限制见 [结构文献核查](../evidence/STRUCTURE_LITERATURE.md)。

## 联合抽样与概率解释

每个情景同时给七个 $x$ 抽一个冻结温度、一个共享原子势误差因子、一个共享结构观测校准偏差，加各组成/构型族的局部扰动。原子势误差因子同时传到构型能量和潜在族输运量，组成及族的载荷不同。BME 对扰动后的训练观测作重拟合。权重区间是这些合成扰动与重拟合下的 5%–95% 情景分位范围。正式研究需要独立结构与原子数据识别协方差和误差幅度，或将区间作为透明的敏感性结果。

族级六个伪随机重复的均值和有限重复标准误用于抽样族潜在均值。真实 MD 需要独立启动轨迹、迁移事件数、尺寸和截断窗口收敛。上线前冻结统一势版本、温度、轨迹协议与集体电荷输运的主指标，另报自扩散和 Nernst–Einstein 估计。实际轨迹种子、尺寸、时间、温度、跨笼跳跃、势版本及诊断应逐条入库；`synthetic_trace_inputs.csv` 记录了这里只用于验证代码的伪随机数值。

在同一共享情景内，按各组成的 BME 权重抽结构族条件分布，保留共享参数造成的依赖。概率三元组用同一对差值直接得出 $P(S_A-S_B>\delta)$、$P(S_B-S_A>\delta)$ 与 $P(|S_A-S_B|\le\delta)$。主演示阈取 $\delta=\log(1.10)$，敏感性为 0、$\log(1.05)$ 和 $\log(1.20)$。每个情景得到一组三元组，跨情景平均报点值、独立外层情景均值的 Monte Carlo 标准误，并给情景分位区间。区间同时含内层 Monte Carlo 波动，解释为设定范围下的不确定性。加权 ECDF 直接对情景内所有离散族分值用其 $w_i$ 加权，避免额外抽族噪声。Top-1 / Top-3 由每个七元联合样本的排序计算。相同浮点分值的极偶然确切并列用固定原始次序；优势三元组依照近似并列宽度。两两优势可以不传递，解释以三元组为主。

`thermal_prior` 与 `uniform` 共用候选、合成输运场景及抽样随机数，分别省略证据重加权和权重区分。输运阈值 $\log(1.30)$ 只作合成晶内示范。压片宏观达标另需独立湿实验或验证后的晶内—微结构—压片映射。真实验证按组成、结构族、轨迹和批次隔离，比较势更新需先固定评价集、权重和计算协议，再单独做联合更新。

## 输出接口

| 文件 | 读取方法与内容 |
| --- | --- |
| `pairwise.csv` | 主方法筛 `method=bme, primary_delta=true` 得 49 行。`x_a` 是行、`x_b` 是列，`p_plus/p_minus/p_tie` 和为 1。概率同时有 Monte Carlo 标准误与情景分位数 |
| `weighted_ecdf.csv` | 按 `method,x` 分组，横轴 `log_relative_transport`，纵轴 `ecdf` |
| `coupling_sensitivity.csv` | 固定主阈及两侧边际，比较同情景联合抽样和错误删除共享依赖的边际乘积分布 |
| `family_weights.csv`、`metadata.json` | 族计数、前向代理量、合成能量和退火情景的先验/更新权重、区间及运行配置 |
| `structure_diagnostics.csv`、`structure_support_stress.csv` | 中央情景的 $\lambda$、训练及留出代理、权重退化诊断和支持外反例 |
| `composition_summary.csv` | 各组成的 Top-1、Top-3 和示意晶内阈值概率 |
| `public_direction.csv` | 与 Mo 七种配方的 21 个历史点值方向对照，含 0、0.1、0.3 mS/cm 阈敏 |
| `des_structure_prior.csv` | `x,structure_state,prior_probability,synthetic_only`，每组 3 行、和为 1。合成热先验在结构证据之前聚合，供 DES 初始化 |

历史方向按差值超过指定 mS/cm 门槛判定。计算端一侧的优势点值至少 0.67 且相应情景下分位大于 0.5 时给方向，近似并列概率至少 0.5 时给近似并列，否则标为不确定。七项历史值来自同一公开开发/回顾性研究，配方共享这些观测之间的依赖，21 对只作工作流展示。Table S1 未提供独立批误差，绝对差与方向支持字段不构成压片优势概率、概率校准或显著性检验。

默认运行的主示例，$x=0.4$ 相对 $0.5$ 的三元组约为 (0.135, 0.641, 0.224)。按 0 mS/cm 门槛对照，21 个方向均留在“不确定”；门槛为 0.1 mS/cm 时，另有一对历史差落在门槛内。中央 $\lambda=1$ 的有效族数量约 6.55–7.55（每配方 9 族）。这些是合成输入下工具的输出，不能作为材料性能、实验权重或 DPA4 准确性的证据。
