# 分层验收与失败后行动

本协议冻结 H1/H2 的终点与版本使用条件。阈值为本课题的**拟定容差**，实际值须根据 DFT 收敛误差、独立重复分散度与候选决策容忍度在开发阶段登记。未执行 DFT/MD/样品结果确认。

|层级与盲法|测什么|初始通过条件|失败后的定位|
|---|---|---|---|
|原子 / 独立参考|按 Li、P、S、Cl、Cl 邻域、跳跃鞍点邻域报告 E/atom、F 分量 RMSE 和 p95；配对同胞同组成路径 ΔE|原子层目标为能量 ≤10 meV/atom、Li 与关键环境力 ≤0.10 eV/Å、独立迁移能差绝对误差 ≤0.05 eV。并报告各族样本/父轨迹数与组 bootstrap 95% CI|先检查单位、DFT 口径、类型映射、对称、温度覆盖。读数超过容差且可能改变关键行动，再选补标|
|迁移与动力学 / 相同设置|物相保持、最短距离、势能漂移、MSD、跨笼跳跃、D 的区间、候选排序|每条件 ≥3 独立初速度及代表性占位，拟初设步长 1 fs，与 0.5 fs、较大盒对照。NVE 漂移起点 ≤1 meV/(atom·100 ps)；有足量独立跳跃才报告 D，按独立副本区间和排序可靠性验收|力过关而跃迁数不足，优先延长及增加独立种子；构型塌陷先检查边界和物相|
|样品 / 独立重复制备|相、组成、密度、实际温度、装夹与几何；同条件总电导、频谱拟合的不确定度；样品层残差及错排|同等级候选与独立批次的排序方向一致或误差落在预登记容差内；例如 ±0.30 log₁₀(S/cm) 为初议样品容差。批次数少只做区间与病例报告|相不符改输入；装夹异常先复测；多个解释同时保留。只有独立参考确认势偏差才能改模型|

**H1 贡献判据。** 同预算下对随机及分歧＋多样性两臂，比较定向臂在留出关键环境力误差和迁移能差的成对改善；以独立轨迹/构型族为抽样单位。先约定关键族力 RMSE 减少 ≥10% 且 95% 成对差区间支持改善，同时源域及输运门槛通过。开发另预登记输运终点和模型版本。样本不足使区间跨零，结论记为未证实；若只对随机有效，不能声称超越强基线。源域检验允许相对退化 ≤10%，接近零误差时另列绝对差。旧势若已过全部目标、无决策差异或新势在冻结时点未通过，沿用旧势。

**H2 归因。** 按独立专家/DFT/复测汇集的事后证据集，对盲选行动逐项记录“针对了得到支持的层次/仍不确定/证据否定”。事后评审允许同时选择结构、势、取样和样品层。对比仅改结构、固定规则、可选行动三种方法。主终点为每个独立确认样品的错误层次任务数与错误淘汰数，并报告观察不到真因的比例。

## 已发表中间组成怎样进入比较

Wang 等实测了氯系列 x=0、0.25、0.50、0.70；Adeli 等在 298 K 对同一名义组成为 x=0.50 的冷压和烧结样品分别报告 9.4±0.1 与 12.0±0.2 mS/cm。将这些已知结果登记为样品层回顾性外部对照。它们提供可比较的组成、输运量级和加工敏感性，不能提供同构型的 DFT 能量或力，也不能计入本项目未见盲验。 [Wang 等的氯系列](https://doi.org/10.1016/j.xcrp.2024.102314) · [Adeli 等的同组成加工对照](https://doi.org/10.1002/anie.201814222)

|比较前记录|如何判读|
|---|---|
|原论文及图表位置，名义与实测组成，测到的相/占位及不确定性，合成与退火热史，冷压/烧结、相对密度，测试温度，输运量类型、单位与误差|先在同研究、同温、同加工条件下列出可比较组成及由高至低的测量排序。条件未报写“未报”；缺少关键条件时只陈述该样品的数值或量级。NMR 自扩散、MD 集体输运、EIS 总电导各列一项。|
|拟比较的结构族、构型清单及其散列，DFT 泛函和数值设置，势版本、独立轨迹与预测排序|先锁定构型族和同构型参考，再计算势误差。若外部量级冲突，先核相、热史、温度、致密度、几何及测量定义；跃迁不足时补独立轨迹。仅当未见构型上的同口径 DFT 证实关键力或能差偏差、并足以改变决策时，进入补标或 M2。|

公开文献可用于预先提出假说；已经看过的排序不参与盲测打分。最终样品检验仍按预登记方向、主工艺和最小可行动差，使用新制备的独立 A/B 批次。

## 从 Li 轨迹到可比较的物理量

在热平衡体积下先平衡、后固定体积采样。检查三维周期解缠并按框架去漂移；若胞随时间变化，先检查选用的参考晶胞处理，避免将形变计入扩散。对 N_Li 个离子的多时间原点平均定义 MSD(τ)=⟨Σᵢ|Δrᵢ|²/N_Li⟩。三维近各向同性时 D_self=lim(τ→∞)MSD/(6τ)。相关位移保留交叉项，D_charge=lim⟨|Σᵢ Δrᵢ|²⟩/(6N_Li τ)，适用于 Li 单一载流子、其余框架无净传输的近似。σ_NE=n q²D_self/(k_B T)，σ_collective=n q²D_charge/(k_B T)，其中 n=N_Li/V，q=e；该定义下 Haven 比 H_R=D_self/D_charge。多种移动载流子时按各自电荷加权，报告统计相关。扩散单位 1 Å²/ps=10⁻⁸ m²/s；σ 由 SI 的 S/m 除以 100 得 S/cm。压片总电导还包括多相、连接路径、晶界和测量条件。

预设 400/500/600 K 作为采样起点并检查相稳定，每个组成至少三种独立初速度；开发时拟从 ≥100 ps 生产段开始。汇报拟合时间窗、斜率稳定区、跳跃数/停留时间、自相关时间和重复间区间。可设 ≥20 次去相关跨笼事件为探索性最低门槛，报告独立数的定义和门槛敏感性。跨温 Arrhenius 拟合须同相、拟合机制一致并传播不确定性；高温外推另列，禁止当作 298 K 实测。成本随原子数/硬件/步数记录。在给定样品条件下仅将可比的趋势、校准与区间送入样品层。
