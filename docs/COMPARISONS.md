# 贡献归因和强基线

输入为有共同预算、已经释放的信息以及决策时刻。输出为选中的任务、理由、依赖版本、到达时间、成本和独立评估结果。H1 与 H2 的实验均为拟执行；本轮 H3 数值见 [已运行 DES 结果](DES_RESULTS.md)。

| 切换 | 固定项 | 应报告的差异 | 什么会削弱解释 |
|---|---|---|---|
| 随机 → 分歧+描述符多样性 → 湿端约束后分歧+多样性 | 同一允许的标签池、每轮标签数、基础势、拟合预算；隔离留出 | 关键结构族 E/F 学习曲线对已购标签数的面积、迁移能差、遗忘及耗时 | 训练与留出共享同轨迹或端元代替目标配比，可产生虚假提高 |
| 固定结构与固定势 → 仅更新结构集合/样品映射 → 可选补 MD/DFT/势 | 同一批次、相同可见实验信息、同一盲评标签 | 错层、错淘汰、无法区分率、不必要标签费用 | 若真相未知，将其标为未判定并报告分母，避免把所有不一致都当作势错误 |
| B0 → B1 | 固定后续排程、模型、同资源/真值 | 基础相门禁效应、空耗与错淘汰 | 报告较晚或 QC 误判时亦可无效 |
| B1 → B2 | 同样预算、观测噪声与可选候选 | 已发布中间信息与成本感知序贯选择的贡献 | 若只实现成本感知代理，不能视作复现完整 GP/多阶段 BO 论文 |
| B2 → B3 | 固定势，同等行动、保证信息释放规则 | 显式瓶颈、队列占用及样品/结构动作的联合差异 | 同时更改动作与排程时，有关队列的单独因果解释要靠 B3 中关闭单一开关的消融 |
| B3 → B4 | 同一实验平台、预测任务、构型假说与初始势 | 开放定向 DFT、合批、验收与版本重算后对首次独立确认和净成本的增量 | 机会成本、验收失败和重算可以抵消适配收益；以 H3 情景区间限定结论 |

**判断顺序**　先报告截止时间前独立确认概率及错误确认，再报告包含超时的时间量与资源。若以筛除真优者换取平均提前，不能声称同准确性收益。决策日志保留“未排队、已排队、开始、不可取消、完成、通过 QC、冻结”时刻。下一轮以历史时间戳校准资源容量和时长，以封存的 DFT/湿实验真值校准误差改善概率。
