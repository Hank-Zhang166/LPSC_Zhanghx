# 氯富集首轮子域与可观察量

首轮讨论母体 Li₆PS₅Cl（x=0）、Li₅.₇₅PS₄.₇₅Cl₁.₂₅（x=0.25）和 Li₅.₅PS₄.₅Cl₁.₅（x=0.5）。三点依赖合作方 SOP 及样品能力确认。每引入一个 Cl⁻ 取代 S²⁻，在这一名义系列中相应减少一个 Li⁺。电中性只限定化学计量，未限定自由阴离子位点占位、Li 排布、次相或晶界。Li₅PS₄Cl₂ 是 x=1 端元，Li₇PS₆ 对应 x=−1，可作跨组成压力测试。二者均不能替代中间组成的验证。

## 首轮组成已有的实验参照

x=0.25 和 0.50 均有已发表的氯富集系列实测。Adeli 等在 298 K 给出 x=0.50 冷压与烧结样品的 9.4±0.1 和 12.0±0.2 mS/cm。Yu 等在同一 350 ℃、15 h 热处理系列观察到 x=0.30、0.50 的室温电导分别为 6.41、3.84 mS/cm；在另一 500 ℃、15 h 系列，两者为 4.04、1.11 mS/cm。Wang 等的中子与核磁研究覆盖两个计划中间组成。这些比较提示名义氯量、进入目标相的氯量及加工条件需要分栏记录。[样品与方法逐条对照](../refs/literature_transport_benchmarks.csv)

初筛要检验本批样品支持的占位与输运解释。已有的中间组成样品测量不能填补所审计原子包中缺失的目标局域 E/F。设计新增 DFT 时，以经过相/成分筛选的多个候选构型族为单位，保留同族的独立检验构型；样品层排序则以预登记的新粉体为单位核对。

## 从化学式生成可证伪的输入

| 步骤 | 拟输入 → 输出 | 验收与淘汰 |
|---|---|---|
| 建候选晶胞 | 文献原型、被允许的占位、化学式 → 整数原子超胞。四个式量下 x=0.25 对应 Li₂₃P₄S₁₉Cl₅，x=0.5 对应 Li₂₂P₄S₁₈Cl₆ | 核对电荷补偿、原子数、周期最小距离、坐标和单位，剔除不合理近邻；四式量只证明可表示配比，有限尺寸效应仍须检验 |
| 建构型族 | 每个配比枚举/抽样 Cl/S 在自由阴离子位点的交换，配对多种 Li 空位安排，区分有序、混排、短程相关、局域异常及迁移过渡邻域 | 距离/局域描述符聚类、记录 supercell、原型、占位 seed、温度、母轨迹；同家族分组后切分 |
| 用湿端约束 | 相鉴定和成分报告 → 删除或降权明显矛盾的结构，保留仍相容的多个假说 | 粉末 XRD 可辨候选相，Li 占位和局域相关通常不唯一；把无法区分的结构保留给局域谱学或独立 DFT |
| 分配 DFT | 先补 x=0.25/0.5 的未覆盖近邻、两极占位假说和迁移相关结构，再补热扰动；各类至少保留独立检验样本 | 先验证同一参考的收敛及基线对比，按族封存真值；筛除重复近邻帧，记录每个标签对哪个行动有意义 |
| 建立样品尺度解释 | 粉体谱系、成分误差、压片条件、相对密度、厚度/面积、阻抗拟合与温度 → 条件化比较 | 识别电极接触、孔隙/晶界与仪器异常；保留 EIS 原始谱和拟合区间，配对估计与独立新批次确认分开 |

四类观测服务于不同问题。XRD 和组成限制输入结构集合；多条重复轨迹限制晶内输运估计的区间；相同几何、独立 DFT 的 E/F 直接审查势误差；同粉体不同加工条件改变样品尺度解释。触发整批训练前还须证明关键误差能改变候选行动、预算可承受且新版本赶得上冻结。

已发表的先例包括不同混料路径可汇合至相似最终组成、Li₆PS₅Cl 压片中孔隙/接触的影响，以及特定外源阴离子空位设计出现高形成能与替代成相。这些证据只用于设计互相竞争的解释。本项目未新增合成、衍射、阻抗谱或 DFT。见 [E16–E18 与 E04](../refs/EVIDENCE_SOURCES.md)。
