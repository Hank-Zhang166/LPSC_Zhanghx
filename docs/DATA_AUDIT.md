# 公开数据覆盖与隔离审计

**审计实践**　读取官方版本的原子归档、实验 CSV、AIS/DaRUS API 和原论文。单个文件中记录的原子数、帧数和重复块与原作者报告量分别列出。下载链接、版本、许可和摘要在 [机器可读清单](../configs/dataset_manifest.csv)。本仓库发布聚合输出及 Python 标准库复核脚本，不打包第三方原始权重、赝势或数据。

## Oxford 的力标签到底包含什么

从 `230923_PBEsol_28100.extxyz` 每个 Li 的三个 forces 分量计算欧氏模。所有 Li 原子出现等权，线性插值求分位数。原始字段无显式单位，按 ASE extxyz 常用约定读取为 eV/Å，物理量仍须与源计算设置核对。下列数据仅描述参考标签的量级，未执行模型推理，因此不能计算模型误差。

| 化学式 | 帧数 | 有限 Li 力模数 | 中位 | P90 |
|---|---:|---:|---:|---:|
| Li₆PS₅Cl | 22,500 | 540,000 | 0.5121 | 1.0801 |
| Li₅PS₄Cl₂ | 2,800 | 56,000 | 0.4925 | 1.0482 |
| Li₇PS₆ | 2,800 | 78,400 | 0.5646 | 1.1361 |

不能从这些混合构型直接推断温度效应、迁移势垒或掺杂因果效应。后续应对同一几何计算模型力减独立 DFT 力，按构型族报告 RMSE。力参考数据本身不包含预测残差。见 [复算脚本](../refs/oxford_force_profile.py)、[全精度输出](../refs/oxford_force_profile.json)。

## 可执行的数据隔离和准入

1. 下载后先核对散列与外部许可。记录源版本、晶胞、几何哈希、能源参考（含交换关联、赝势、截断、k 点、收敛阈值）、stress/virial 张量序与正负号。Oxford stress 不直接复制到 DeePMD virial，先对同几何有限应变的能量导数验证换算、体积与单位。
2. 区分实测标签、DFT 标签、教师伪标签三条谱系。SSE 与 Oxford 即便同名 PBEsol，也先对重合/专门桥接构型核验能量参考、力分布和应力；仅对常数偏置做原子参考能修正并不能消除力残差。无法桥接时各建单独评估表。
3. 优先按 parent/trajectory/structure family 分组，合并严格重复和近重复；周期平移、原子置换与不同超胞需做 PBC 感知近邻描述符或结构匹配。缺轨迹 ID 时采用连续块+构型簇，比较多种块长，按最悲观的外测报告。每组仅进一折，最终 x=0.25/x=0.5 或留一迁移环境整组封存。文献预训练可能见过的组成标作“可能污染”，另留全新 DFT。
4. 先花小预算挑真实湿端允许的中间结构族，优先局域 Cl/S 交换、Li 补偿和迁移关键帧；训练、筛选和组级盲测的几何独立。DFT 只报告结构 E/F/virial。独立粉体的密度、成分、EIS 和确认时间归另一张表。
5. 接受一个外部池的条件是能答复“谁生成、如何分组、标签单位、参考口径、是否污染、允许何用途”。缺失项目保留缺口和负责人接口，暂限为先验/定性核对。公开标签池的预算回放需在未来执行逐轮预测和标注记录；本轮已计算的是标签组成与力模。DES 的随机误差改善与时长是另一层情景参数。

## 复核命令

从仓库根目录执行。先按清单下载到外部目录，将以下文件参数替换为真实路径。脚本只读归档，以 JSON 写标准输出。源 zip 中的模型、POTCAR 不解包到仓库。

```sh
python refs/audit_public_files.py oxford datasets.zip
python refs/oxford_force_profile.py datasets.zip
python refs/audit_public_files.py deepmd 20240412-SSE.zip
python refs/audit_public_files.py deepmd SSE-abacus.tar.gz
python refs/audit_public_files.py darus4510 data.zip
python refs/audit_public_files.py obelix all.csv
```
