# 可执行的湿端先导与独立确认
本方案用于合作方讨论。配料与安全工艺以场地批准的硫化物 SOP 为准。版本 P8.0，2026-11-23。三种组成只是名义设计，尚无本项目粉体、阻抗谱或设备预约。
## 批次与分样
以每个 P=1 归一化，x 取 0、0.25 和 0.50。两个独立制备区组内各制三种组成。将区组内实际执行顺序随机化并记录，同时在区组内平衡测量次序。每个粉体分成 L/H 两种已获批准的可比压实条件，各做一片。绑定盲法谱编号，不在原始拟合表显示名义组别。以粉体为统计单元，以粉体内差估计加工敏感性。条件不可比或失效时保留原记录、失败原因与缺失标记。
## 冻结与确认
团队在比较之前冻结 SOP、目标温度、候选纳入标准、主压实条件、几何与谱拟合规则。首轮六批用于辨识分歧，按预先承诺的规则锁定一对 A/B 排序，注明不确定性、使用的势版本及允许的时间窗。A、B 各另制两份新粉体，每份仅用主条件制一片。复核因此共十粉体、十六片。预先冻结 A/B 复现方向与最小可行动差 Δ（由实验常规重复误差与使用方要求共同确定），不以新批结果反调阈值。
同向且越过 Δ、两次独立区组比较均可解释、相与几何合格，记为“先导支持”。出现反向、明显批间不一致或低于区分能力时，记为“不一致”或“未分辨”。2 个确认批次/组成只可检出明显不稳定，不能替代有功效的总体结论。下轮用先导批间方差与最小效应做样本量设计。记录冻结后因 QC 被动剔除或补做的原因。不得把同粉体 L/H 或重复扫描计入独立样本数。

## 两种同样可能的结局
路径一：相与成分不支持原始单相占位图。将异常候选暂列“未知”，重新枚举相容构型。避免通过微调逼迫势重现实验总电导。以独立 DFT 对少量相容构型做同口径校验。
路径二：相容样品在 L/H 间排序反转，而同一结构族的 DFT 与势一致。优先复查孔隙、接触和量测，采用同粉体差及新批复验判断。若干端迁移采样不足则延长独立轨迹；只有独立参考重复指出局域系统误差才进入定向补标。
## 事件可见性与交接
提交、排队、启动、结束、审核发布、冻结分别打点。未审核结果仅供过程跟踪，决策消费 released_at。长 MD 一旦启动即核算已占用资源。失败或错过冻结的报告仍保留，可能影响下一轮。原始谱、剩余粉体、使用许可与设备容量由合作方确认后再进入真实运行。
## 谁在何时做什么
实验负责人锁定安全 SOP、盲化、压实和测谱可行性。建模人员给出带 hash 的候选构型族、目标标签、冻结排序与预测区间。工业工程人员在不干预决策的影子运行中提取设备忙闲和报告滞后。三方会签版本和异常处理，再独立执行新批次。仓库 pilot/ 提供十份粉体和十六片预登记清单。
