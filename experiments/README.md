# 原子势研究实验册

本表中的七项实验均为拟执行。每次运行记录配置、输入和模型的 hash、随机种子、划分、设备、起止时间、误差及失败原因。当前已运行的实验为独立的 [DES](../simulation/README.md)。所有数值门槛来自[预注册建议](../configs/model_experiments.yaml)，部署前由团队在开发集上冻结。

|实验卡|要回答的问题|
|---|---|
|[M0 冻结势与领域基线](cards/M0.md)|不改变势参数时，哪个候选已经能支持本轮决策？|
|[M1 从头训练的成本对照](cards/M1.md)|相同构型和标签数下，预训练有多大增量？|
|[M2 全量微调](cards/M2.md)|独立 DFT 已发现关键迁移环境力偏差，是否值得对适用域做适配？|
|[M3 DPA4 原生低秩微调](cards/M3.md)|同预算下，少量可训模块能否实现与 M2 相近的定向改进？|
|[M4 冻结描述符的性质头](cards/M4.md)|在测量条件已知时，原子表示是否带来额外的样品层预测信息？|
|[M5 分参考的多任务对照](cards/M5.md)|两种 DFT 参考均有足够数据时，共享几何表示能否改善目标域而不发生负迁移？|
|[M6 教师到 DPA4C 学生](cards/M6.md)|已验收教师能否以足够低成本支持更长采样？|
