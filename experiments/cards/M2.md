# M2　全量微调

**拟执行。** 独立 DFT 已发现关键迁移环境力偏差，是否值得对适用域做适配？

|项目|实施要求|
|---|---|
|输入与隔离|通过 M0 的合法 .pt、原版 model 参数与全周期词表、相同参考的目标/源训练数据、独立参考证据。|
|初始配置|batch 2；1e−4→1e−6；至多 10,000 步；目标/源抽样 0.6/0.4（无相容源则另案）；16/32/64 帧累进预算。开启描述符、能量拟合头梯度。|
|操作与检查|复制权重 JSON 的 model。修改损失、训练、学习率与数据路径，替换预训练统计文件设置。每 500 步保存；见训练协议外部早停。|
|产物与验收|模型、开发轨迹和版本差异；独立力/能差、源域与长轨迹均过线方可上调。错过发布窗口则沿用旧势。|

启动记录需给出 M0 已锁定的结构族、独立同构型 DFT 误差及它可能改变的候选行动。即使预测与 x=0.25 或 0.50 已发表样品的输运量级相差较大，也须先复核相、热史/加工、测试温度和轨迹收敛；仅有文献差异时不开放势参数。验收仍使用封存的组级参考，样品排序另由冻结后独立新批检验。
