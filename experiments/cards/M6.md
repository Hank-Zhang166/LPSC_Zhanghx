# M6　教师到 DPA4C 学生

**拟执行。** 已验收教师能否以足够低成本支持更长采样？

|项目|实施要求|
|---|---|
|输入与隔离|教师 checkpoint、生产任务实际瓶颈、域内独立轨迹及 teacher 伪标签、与训练无亲缘的 DFT 基准。|
|初始配置|学生 descriptor.type=dpa4c、标准 ener 头，pt-expt；初始 batch 2、1e−3→1e−6、20k 步。教师固定；加入训练内 DFT 锚点为单独消融。|
|操作与检查|从官方 DPA4C 示例替换样本和标签路径。教师与 DFT 分账。暖机后实测同平台的 ps/day 及单位步成本。|
|产物与验收|学生 checkpoint、真实 DFT 验收、log D 对照、加速与回本天数。速度或迁移任务失败即维持教师。|

入口模板采用实际系统路径和变量替换。以“伪代码”开头的表示科研步骤。下列调用均未在本次任务运行。

```text
dp --pt-expt train student.json
```
