# M0　冻结势与领域基线

**拟执行。** 不改变势参数时，哪个候选已经能支持本轮决策？

|项目|实施要求|
|---|---|
|输入与隔离|Plus、Neo 的 v20260805 .pt 与 JSON；DPA-SSE 的授权兼容权重及推理环境。三者共享构型清单，用相同原子排序和单位。|
|初始配置|训练步数 0。每个 system 均逐帧评估所有预登记测试帧；记录帧数，禁止只报命令默认取样。可另设 training-only 偏置校准，校准和原始结果分开。|
|操作与检查|N 替换成该 system 的实际帧数。DPA-SSE 用其原生后端运行并按 frame_id 汇总。配对计时先暖机，报告精度、规模、硬件、步长、均值与波动。|
|产物与验收|盲测预测表、元素与环境误差、能差、硬件耗时与适用域。现有势达标且排序稳定即保留。|

入口模板采用实际系统路径和变量替换。以“伪代码”开头的表示科研步骤。下列调用均未在本次任务运行。

```text
dp --pt test -m DPA4-Neo-OMat24-v20260805.pt -s path/to/system -n N
```
