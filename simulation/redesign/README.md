# 新批名额分配试验

七种组成已完成同口径的首轮初筛，但下一轮只有一个独立粉体确认名额，且名额必须在工时冻结点锁定。这个试验回答一项可核查的问题：冻结之前应向哪个组成追加哪项证据、何时等结果或并行、在相同投入上限下能否改善一次真正成功的独立确认。它从初筛报告发布时开始计时，父目录 `simulation/p9` 保存上一版覆盖制样到审核的全过程试验。本实验的入组条件、结果和种子均单独冻结。

## 运行

依赖 Python 3.11 或以上和 NumPy。运行目录为此 README 所在目录，各输入路径按模块位置解析。

```powershell
$env:OPENBLAS_NUM_THREADS = '1'
python run_study.py --workers 8
python sensitivity.py --workers 8
python fit_fixture.py
python register.py
python verify.py
```

主试验以七组成为一个队列，7 种政策×1024 基准重复；5 个压力设定×4 种政策×256 重复，共 12288 条政策／队列评价。开发集另有 192 组×4 种政策×6 个门槛；独立风险评价 512 组×4 种政策；联合扫描为 24 组参数×96 个共同种子×3 种政策。种子空间分别起于 874031、908100、912500、933400；联合剖面刻意使用相同 96 个共同种子，便于比较参数变化。主设计点含 5.0 情景 mS/cm 的长期目标、32 h 共用冻结、72 h 观察窗、2100 情景元诊断预算和 770 情景元确认留额。首轮初筛成本是各策略共同的入组沉没成本，不计入追加及确认费用。没有现场运行或实报实销。

## 何处共享，何处独立

每个候选隐状态含结构低中高档 F、长期配方－SOP 接触风险 C、局域势偏差 B、首轮粉体实际制备结果 B1。合成构型先验来自 `../../p9/ranking/outputs/des_structure_prior.csv` 中的 21 行，含合成标记且逐组成归一。此处保留每组成的三档概率，未传播原始全部后验样本；分档与长期目标映射是透明的情景假设。七组成的 Mo 电导实测没有进入先验、策略或真值生成。

离散 F 临时映射为 3.9、5.4、7.1 情景 mS/cm；C 为真时扣减 1.6，得到长期目标指示 D。C 是在固定工艺下持续存在的接触不利倾向，B1 是当次制批实现，二者没有互换使用。D 为真或假时，实际粉体达标的情景概率分别为 0.94 或 0.10。初筛 EIS 与同粉复测以同一个 B1 为条件分别抽读数；这自然保留同粉相关性。新批 B2 在冻结后独立抽制备结果，条件只依赖 D，再按新批读数灵敏度 0.94、特异度 0.975 抽审核读数。D、B1、B2 和真假测量结果都在外层评价控制下。新批未建模的因素包括试剂批号、环境漂移和连续阻抗谱拟合，需要现场先导估计。这些二元读数并不是独立合成实验的实测数据。

环境 G 表示同一个势在该项目中存在偏高局域误差普遍率的状态。G=低/高时每个候选局域误差的先验概率为 0.09/0.64。F、C、B 可以并存。更新采用 P(G) 与条件于 G 的七个 24 状态表，归一化后与完整联合后验等价，避免枚举 24 的七次方个联合状态。一个组成的 DFT 读数更新 G，从而通过其他组成已有 MD 证据影响其相对提名价值。去共享消融保留相同单组成偏差边缘先验，移除跨组成更新。A/B 两个可迁移局域域登记在 `project.json` 的 `local_domains`，按组成交错分配仅是合成占位。真实项目须用局域描述符/结构家族标定迁移范围，不能解释成梯度组成天然存在的两类近邻环境。

## 判断与调度

稳态决策目标是提升合格提名的收益，错误提名的损失按 ρ/(1−ρ) 倍计，弃权为 0。给定候选长期达标概率 p，提名的期望效用为 (p−ρ)/(1−ρ)。至少一份同粉初筛／复测阳性是入围硬条件。终端效用取合格候选与弃权中的最大值。ρ 的主设计值为 0.68，另外在开发集搜索六个门槛。单步行动通过所有后验读数分支计算上述全队终端效用的期望增量，而非只看该配方方差；低于 0.004 效用单位可保留资源。每个实际决策都受预算、剩余分样、当前资源、审核和冻结前预计发布时间约束。两步把第一步的首选项限制在单步得分前三，并另纳入最高分的 DFT 和适配候选；每一分支中的所有可行第二步均进入比较。内层使用按已知工序时钟展开的代表性时长；服务尾部、再后续行动和完整多项目排程不在搜索深度内。不同候选的互相挤占通过共享资源和唯一名额内生进入。

已有一项在制时，单步考虑立即并行提交在已预约报告之外的增量；两步还比较“现在并行”与“等该份报告后再按结果选择”。没有足够时限会停止；可行且超出增益下限时才恢复下单。负荷和在制上限会限制预测与实际日历；工序在提交后经排队、独占运行、完成、人工审核和发布，只有发布改变后验。资源包括制片、结构表征、GPU、DFT、审核、炉；各一个槽位。费用在各阶段开始时发生，提交时占用整包上限。未开工任务在冻结时可取消并返还未用额度、分样；已开工按不可抢占处理。真实外送和炉前段的长周期供给由原 P9 全流程场景处理，本试验不以简化的单槽代表宜宾现场实有设备。各工序时长与成本见 `lab.json`。

固定门禁（gate）按当前后验前三项依序分样、MD、有初筛冲突再 DFT。仅初筛（screen_only）允许弃权并使用相同独立新批流程。myopic 和 tree 使用相同动作和资源限制；tree_fit 额外允许出现独立阳性诊断 DFT 后的一项定向适配包。补标签、训练、独立留出验收、发布、选择性重算占用 DFT、GPU 和审核槽；预留预算覆盖整个包。验收失败沿用旧势，验收通过后有明确的发布事件，再等新轨迹报告。旧、新 MD 为独立启动轨迹，共享局域误差状态。没有读取实验 EIS 作为 E/F 监督。训练效果与模型版本迁移均使用情景代理；诊断、补标和留出三次 DFT 的用途分开，不会把模拟接受标志解释为真实能量／力验收。tree_serial 只允许一个在制诊断；tree_no_share 移除候选间的势偏差共享。

## 如何读输出

|文件|内容与分母|
|---|---|
|outputs/policy_summary.csv、paired_effects.csv|每政策的整队列均值；差值先按相同种子相减，区间为差值均值 ±1.96 个标准误，仅表示有限重复误差。稀少或零观测不足以界定真实发生率，discordant 记录样本中有差异的队列数。|
|outputs/replicates.csv.gz|主试验逐队列、逐政策结果；success_rate 须同时长期达标、新批实际达标、读阳并按时发布；wrong_nomination 为长期不达标却获提名；wrong_release_rate 为读阳但上述真实条件至少一项不满足；miss_rate 在全部队列上统计有长期达标机会却未成功的队列。|
|同文件的成本和时间列|mean_cost 为初筛后实际发生的诊断及独立新批费用；restricted_h 为任何新批阳性读数的发布时间、未读阳按 72 h 截尾；不要求可见读数对应长期和新批的真实双达标。|
|同文件的诊断列|dft_count 仅指诊断 DFT；clean_dft_count 是无潜在局域势误差却进行的诊断，不等于这一排除动作毫无价值；false_bias_flags 是冻结前假阳性的诊断 DFT 数。missed_bias_count 是有潜在局域偏差却无冻结前阳性诊断的组成数。除以累计 true_bias_count 可得漏诊比例；该目标与抢独立新批名额的效用不同。|
|同文件的训练列|fit_count 是自愿下单量，accepted_fit 是留出流程通过数；unhelpful_fit 以验收拒绝、真实设定无正修复、或选中对象无偏差定义，是需隐藏真值的代理指标。基准无申请时，条件有效标签率无定义，不能据此声称零错误。|
|outputs/events.csv、counterexamples.csv|按先验规则选取能展示两政策结果不同的第一例，用于解释行动；反向例同步列出，不能据此估平均效果。候选编号在逐队列表与反例表中为整数 0–6，对应 x=0.0–0.6；事件流水中 candidate 直接写 x 值。|
|outputs/development.csv、risk_evaluation.csv、risk_effects.csv、risk_replicates.csv.gz|独立开发种子选共同错误提名风险上限 6.5% 下最高确认率；按最低费用解平局。评价集使用冻结门槛；报告实际风险，未做精确风险配平。|
|outputs/joint_sensitivity.csv|七维分层拉丁超立方扫描，包括冻结时限、审核速度、预算、初筛失准、真实局域偏差普遍率、真实适配效果、跨批可重复性。实际未知参数与规划者所用假设分开。跨扫描点范围与每点配对误差不是一种不确定性。|
|outputs/fit_fixture.json、fit_events.csv、rollback_events.csv|在联合扫描中找到自然请求适配的剖面和种子，用同一已发布前缀强制接受／拒绝两分支，单独检查版本和重算行为。路径检查不计入政策收益估计。|
|outputs/design.json、checks.json|种子和规模、回放定位、门槛决策及自动检查。|
|parameters.csv|由 register.py 根据实际项目配置、工序、观察模型导出的证据分级参数清单，标注来源、计时口径、相关性和待现场核实项。|
|results.md|写入正式开题报告的第 7.2–7.4 节，包括配对差、反例、独立新批与可见读阳的差别。|

## 去现场先校准什么

优先获得一组独立新制粉体和各自的同粉分样，按组成、工艺、制批、压片、仪器、审核编号链接，分解批间波动与批内测量相关性。随后用任务提交、资源开始/结束、审核完成与冻结时间戳重建服务分布和审核拥堵；用相同工艺一段时间内的信息检验跨候选势风险证据是否可迁移。待确认名额数、质量门槛、错误提名代价、真实预算和可改变行动的发布时间均需合作方预先冻结。若合作方有多名额或不可共享的冻结窗口，应改写终端行动空间并重新运行，不能直接挪用一名额结果。
